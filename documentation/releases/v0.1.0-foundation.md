# v0.1.0-foundation

Foundation snapshot, 2026-11-21. This is the source baseline before building
the real OS image. It is a prerelease, not a completed OS or game engine.

## Included

- Warp object graph, readable Weft subset, pure Knight calculations, native
  x86-64 JIT, transactional graph writes, explicit imports, and scoped grants.
- One Makefile for Windows, Linux, and standalone x86_64, with other registered
  architectures reported as unsupported instead of producing dummy binaries.
- Windows and Linux worker containment, normalized input, software/OpenGL
  framebuffer presentation, managed byte storage, and loopback networking.
- Optional PCM audio and clipboard mechanisms.
- Standalone x86_64 UEFI binary and boot ISO build rules, framebuffer, timer,
  PS/2 input, serial CLI, and trusted integer JIT execution.
- Canonical image at neo/neo-os/image.neo, including the lifecycle exercise.

## Verified

Windows and Linux Make suites pass, including native worker failure recovery,
package grants, live edits, rollback, event delivery, source views, platform
contracts, presentation, and persistence. Two exercise processes restore and
save values 0 -> 5 -> 10. Snapshots reopen without host authority. Failed edits
and saves preserve prior state. Shutdown cancels timers and pending I/O.
Standalone surface and CLI boot profiles are checked with QEMU and OVMF.

## Remaining work

General asynchronous graph I/O and atomic whole-image checkpointing are not
complete. Scalar documents and graph checkpoints are independent records.
The standalone profile lacks worker containment, binary64 support, persistent
disk storage, networking, USB, and audio drivers. Real hardware is unverified.
The ISO is boot media, not an installer. Drag/drop, hotplug, broader device
recovery, and the actual desktop, applications, and engine remain future work.

## Packaging

This release contains the essential source, canonical image, tests, license,
and current guides. Build outputs, caches, unused assets, migration scripts,
and retired-runtime guides have been removed. Git history preserves the prior
implementation. The whitepaper is retained unchanged by this cleanup.
